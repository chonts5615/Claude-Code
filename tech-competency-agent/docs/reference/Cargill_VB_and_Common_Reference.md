# Cargill V&B and Common Competency Reference

This document is the boundary-classifier truth source. Every candidate
competency must be tested against the V&B and Common boundaries before being
admitted to the Technical library.

## Values & Behaviors Boundary (6 V&B terms)

| V&B term | Trigger keywords | Rule |
|----------|-----------------|------|
| **Do the Right Thing** | integrity, ethics, honesty, compliance posture, "doing what's right" | If the competency centers on personal/ethical conduct rather than a domain skill, classify as V_AND_B. |
| **Put People First** | empathy, inclusion, listening, psychological safety, well-being | If the competency is about how the person treats others (not what they produce), classify as V_AND_B. |
| **Reach Higher** | growth mindset, learning agility, ambition, continuous improvement of self | If the competency is about personal aspiration or self-development, classify as V_AND_B. |
| **Act as an Owner** | accountability, follow-through, ownership posture, commitment | If the competency is a stance toward work (not a method), classify as V_AND_B. |
| **Bias for Action** | decisiveness, urgency, momentum, "just do it", initiative | If the competency describes pace and initiative as a personal trait, classify as V_AND_B. |
| **Win as One Cargill** | collaboration posture, "one Cargill", enterprise mindset | If the competency describes an enterprise mindset rather than a collaboration method or tool, classify as V_AND_B. |

Operational rule: **V&B describes the person; technical describes the work.**
If you can't point at a deliverable, a tool, a method, or a measurable
outcome, it is almost certainly V&B.

## Common Competency Boundary (5 Common terms)

| Common term | Removed-domain-noun test | Rule |
|-------------|-------------------------|------|
| **Change Acumen** | "Change ___" — if the noun (e.g., "in process", "in tools") is removable and the competency still reads true, it's COMMON. | All-employee competency for navigating change; classify as COMMON. |
| **Technology & Data Acumen** | "Use ___ tools and data" — if generic across functions, COMMON. | Baseline data/tech literacy; classify as COMMON. If domain-specific (e.g., "design ETL pipelines"), classify as TECHNICAL. |
| **Business Acumen** | "Understand ___ business" — if it generalizes, COMMON. | Generic business understanding; classify as COMMON. |
| **Financial Acumen** | "Understand ___ financials" — generic budget literacy is COMMON. | Generic financial literacy; classify as COMMON. If it requires CPA-grade IFRS knowledge, classify as TECHNICAL (Finance family). |
| **Partner with Impact** | "Partner with ___ stakeholders" — if generic, COMMON. | Generic stakeholder partnering; classify as COMMON. If it requires a domain method (e.g., negotiating supplier contracts), classify as TECHNICAL. |

The **remove-the-domain-noun** test: rewrite the competency without its
domain noun. If the rewritten version still reads as a real competency that
applies to most roles in Cargill, it is **COMMON**, not TECHNICAL.

## Disambiguation Examples

| # | Candidate competency | Classification | Why |
|---|---------------------|---------------|-----|
| 1 | "Acts with integrity in supplier negotiations" | **V_AND_B** | Reduces to "Acts with integrity" — pure ethics stance, no method. |
| 2 | "Uses Power BI to build supply-chain dashboards" | **TECHNICAL** | Names a tool and a domain output; not removable. |
| 3 | "Embraces change in process improvements" | **COMMON** | Remove "in process improvements" → "Embraces change" → Change Acumen. |
| 4 | "Designs HACCP food-safety control plans" | **TECHNICAL** | Domain-specific method (HACCP) and output (control plan). |
| 5 | "Owns delivery of Q4 financial close while building team capability" | **MIXED** | Combines V&B (Act as an Owner) with TECHNICAL (financial close); split into two competencies. |

When a competency lands in **MIXED**, the normalizer must split it: one
TECHNICAL competency for the domain skill plus a note for the V&B/Common
component (which is not added to the Technical library).
