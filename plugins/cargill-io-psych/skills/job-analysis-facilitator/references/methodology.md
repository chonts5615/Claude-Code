# Analysis of Work — Methodology

Authoritative process detail for the job-analysis-facilitator skill. Grounded in
the SIOP *Principles for the Validation and Use of Personnel Selection
Procedures* (5th ed., 2018) and the *Uniform Guidelines on Employee Selection
Procedures* (29 CFR Part 1607, 1978), §14C (content validity) and §15.

## Choosing the method

| Work character | Lean toward | Why |
|---|---|---|
| Routine, standardized, procedural | **Task-oriented** (task inventory) | The work *is* the tasks; criticality is observable |
| Judgment, knowledge, relationship work | **Worker-oriented** (KSAO) | Value lives in attributes, not discrete steps |
| Most professional roles | **Hybrid** (default) | Capture both the work and what it takes |

Always end with KSAOs linked to tasks — selection and competency work need the
*requirements*, not just the activity list.

## Task-statement grammar

`Action verb (present tense) + object + context/tool + purpose/outcome`

- One observable unit of work per statement. If it needs an "and," consider
  splitting.
- Present-tense action verb the incumbent would recognize.
- Concrete enough that two SMEs would agree it is/ isn't part of the job.
- 20–40 statements for a single role; cluster into 4–8 duty areas.

**Good:** "Reconciles intercompany balances in SAP each close cycle to ensure
consolidated accuracy."
**Anti-patterns:** vague ("Handles finance things"); trait-as-task ("Is
detail-oriented" — that is a KSAO, not a task); two tasks in one; tool-only with
no purpose.

## Criticality ratings

Rate each task on these scales (5-point unless noted). Collect from SMEs
independently, then aggregate.

| Scale | Anchors (1 → 5) |
|---|---|
| **Frequency** | Rarely / a few times a year → Continuously / many times a day |
| **Importance / Criticality** | Minor → Critical; errors have severe consequences |
| **Difficulty** | Very easy to learn/perform → Very difficult; long ramp |
| *Consequence of error* (optional) | Negligible → Catastrophic (safety, financial, legal) |

**Composite task-criticality index** (default, transparent and defensible):

```
Criticality = (Importance × Frequency) + Difficulty
```

Importance is weighted by recurrence (a critical-but-rare task still scores via
Importance; a routine-but-trivial task stays low). Report the components, not
just the composite. **Essential functions** = tasks at or above the agreed
Importance threshold (commonly Importance ≥ 4), regardless of frequency — a
once-a-year task can be essential.

## KSAO derivation and classification

For each significant task ask: *what must a person know, do, or be — at entry —
to perform this well?*

| Class | Definition | Test |
|---|---|---|
| **Knowledge** | An organized body of information applied directly to performance | "Knows X" |
| **Skill** | A proficiency at a task developed through practice; trainable, observable | "Can do X to standard" |
| **Ability** | A relatively enduring capacity to perform | "Has the capacity for X" |
| **Other characteristic** | Disposition, value, interest, licensure, physical requirement | "Is / holds / can tolerate X" |

Writing rules:
- Observable and verb-led; avoid circular trait language.
- Tag each KSAO **required at entry** vs **developed on the job**. Only
  at-entry KSAOs may anchor a selection procedure.
- Tag licensure/credential KSAOs explicitly (they are bona-fide requirements,
  not preferences).

## Linkage and orphan rules (content-validity core)

- Build a Task × KSAO grid. For each cell, mark whether the KSAO is required for
  that task (and optionally a 1–3 linkage strength).
- **Every KSAO must link to ≥1 task.** A KSAO that maps to nothing is a
  free-floating requirement — the single most common content-validity failure
  and a litigation flag. Either link it or drop it.
- **Every essential task should map to ≥1 at-entry KSAO** (or be explicitly noted
  as fully trained post-hire).
- Flag both orphan types in the matrix.

## SME sampling and agreement

- Use multiple SMEs spanning incumbents and supervisors; document who and why.
- Have 2–3 SMEs independently rate at least a sample (10–20%) of tasks to
  estimate agreement.
- Targets for high-stakes use: inter-rater agreement (e.g., r<sub>wg</sub> or
  ICC) in the substantial range; treat Cohen's/Fleiss' kappa ≥ .60 as
  substantial and ≥ .80 as near-perfect. Where agreement is low, reconcile in a
  consensus discussion and note it.
- In draft mode (no SMEs), label every rating **UNVALIDATED — requires SME
  confirmation** and recommend a validation pass before operational use.

## Documentation (Uniform Guidelines §15)

The report should carry enough to satisfy §15 content-validity documentation: a
description of the work analysis method, the operational definition of the work
behaviors/KSAOs, evidence the selection content is a representative sample of the
work, and the qualifications of the analysts/SMEs.
