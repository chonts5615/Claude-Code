# Exercise Library & BARS Anchor Patterns

Job-relevant simulations to choose from, what each measures well, and how to
write behaviorally-anchored rating scales for the scoring guides.

## Exercise types

| Exercise | Format | Measures well | Watch-outs |
|---|---|---|---|
| **In-basket / inbox** | Individual, written | Planning & organizing, delegation, judgment, prioritization, written communication | Reading-load can confound; standardize volume |
| **Role-play** (e.g. tough conversation, coaching) | 1:1 with trained role-player | Interpersonal skill, influence, conflict handling, coaching | Role-player must be standardized/trained |
| **Leaderless group discussion (LGD)** | Group | Influence, collaboration, leadership emergence, listening | Group composition affects airtime; rotate roles |
| **Case analysis / strategic** | Individual or pair, written + present | Analytical thinking, business acumen, decision quality | Don't let domain knowledge swamp the dimension |
| **Oral presentation** | Individual, to panel | Communication, persuasion, executive presence, handling Q&A | Separate content from delivery in scoring |
| **Fact-find / inquiry** | Candidate questions an info-holder | Information seeking, problem analysis, judgment under ambiguity | Standardize the info script |

Pick a mix so each dimension is observed across **different stimulus types**
(individual + group, written + interactive). That cross-context observation is
what makes dimension ratings trustworthy.

## Linking exercises to dimensions

Common, defensible pairings (adapt to the role's actual dimensions):

| Dimension | Strong exercises |
|---|---|
| Planning & Organizing | In-basket; case analysis |
| Influence / Persuasion | Role-play; LGD; presentation |
| Analytical / Decision Quality | Case analysis; in-basket; fact-find |
| Interpersonal / Coaching | Role-play; LGD |
| Communication | Presentation; in-basket (written); role-play (verbal) |
| Leadership | LGD; role-play; in-basket (delegation) |

## Writing BARS anchors (for each on-cell)

A behaviorally-anchored rating scale describes **observable behavior** at each
level — not evaluative adjectives. Pattern:

- **5 — Far exceeds:** specific high-skill behaviors (e.g. "Surfaces the
  unstated objection, reframes it, and gains explicit agreement before moving
  on").
- **3 — Meets:** the expected competent behavior (e.g. "Acknowledges the
  objection and offers a relevant response").
- **1 — Far below:** specific deficient behaviors (e.g. "Talks over the
  objection or concedes the point without addressing it").

Rules:
- Anchors are behaviors a trained assessor could see and record, replicable
  across raters.
- No adjectives-as-anchors ("good communication"); describe what good looks like.
- Anchor to the **dimension as enacted in that exercise** — the same dimension
  reads differently in an in-basket than in an LGD.
- Provide the 1/3/5 anchors at minimum; 2 and 4 interpolate.

## ORCE reminder for the scoring guide

Each guide should remind assessors: **O**bserve behavior → **R**ecord it
verbatim → **C**lassify it to a dimension → **E**valuate against the anchor.
Evaluation comes last, after the behavior is recorded — this is the discipline
that keeps ratings defensible.
