# Deliverable Specification — Career Architecture

Apply `cargill-branding` (Leaf Green headers, White Green zebra, Arial body,
Georgia titles).

## Excel — `career_architecture_<family>.xlsx`

### Tab 1 — `Leveling Matrix`
Rows = levels (both ladders interleaved or in two blocks: IC1…ICn, M1…Mn).
Columns:

| Column |
|---|
| Track (IC / Manager) |
| Level code (IC3, M1, …) |
| Level name/title |
| Scope (descriptor) |
| Complexity (descriptor) |
| Autonomy / decision-rights (descriptor) |
| Impact (descriptor + horizon) |
| Equivalent level (cross-track) |

Freeze the header and the level-code column. Shade the two tracks differently
(within Cargill palette).

### Tab 2 — `Role Placement`
| Role | Family / sub-family | Placed level | Rationale (which factors drove it) |

### Tab 3 — `Distinctness Check`
For each factor, list adjacent level pairs and a PASS/REVIEW flag. Conditional-
format REVIEW (amber) where adjacent descriptors are too similar — these must be
rewritten before sign-off.

### Tab 4 — `Progression Criteria`
| From → To | Demonstrable evidence required (observable, factor-aligned) |

## Word — `career_framework_<family>.docx`

1. **Purpose & scope** — families covered, why now.
2. **Structure** — family → sub-family → level; number of levels; dual ladder.
3. **Leveling factors** — the four (or five) factors and their progression
   language.
4. **Level summaries** — a paragraph per level (both tracks), grounded in the
   factors.
5. **Dual-ladder logic** — equivalence and how IC vs manager impact differs.
6. **Progression criteria** — what moves someone up at each boundary.
7. **Role-placement examples** — a few roles mapped, with rationale.
8. **Governance** — how placements are decided/calibrated; pay-band alignment
   note (validate with Total Rewards).
9. **Disclaimer** — the standard block.

## Hand-off note

End with a "Feeds" line: the architecture anchors role profiles, competency
expectations per level (TCB v3.1), interview level-differentiation
(`structured-interview-generator`), and pay-equity analysis.
